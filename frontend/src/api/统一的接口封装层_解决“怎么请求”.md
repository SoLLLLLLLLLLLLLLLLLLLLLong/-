“前端所有要访问后端的地方，都不要自己直接写 fetch，而是先封装成函数，谁需要就调用谁。”
比如里面有这些函数：
login(payload)
register(payload)
getCurrentUser()
getConversations(userId)
getConversationMessages(conversationId, userId)
createConversation(userId)
uploadKnowledgeFile(file, userId)
streamAgentChat(messages, userId, conversationId, indexId, signal)
getWeather(city)
这些函数本质上都干一件事：调用 request()，再通过 fetch() 向后端发请求。
